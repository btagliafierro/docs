    How-To: Use ParaView to Visualise DualSPHysics Results¶

    Use PartVTK to export saved DualSPHysics v6 particle results, then ParaView to inspect VTK data and time series. Existing initial GenCase VTK files can be opened directly.

    1. Open the initial particle configuration¶

    1. Start ParaView and choose File → Open.
    2. Select the case's existing initial boundary and fluid files, for example CaseName_Bound.vtk and CaseName_Fluid.vtk.
    3. Select each loaded item in the Pipeline Browser and click Apply in Properties.
    4. Use the visibility controls to show fluid and boundary together.
    5. Reset/orient the camera and inspect particle distribution and geometry.
    6. Choose an array actually present in Coloring, such as Rhop when available.

    Availability depends on the case and GenCase's save selections, including vtkbound and vtkfluid among the -save options. Do not assume every case has both files. This guide starts from existing output rather than requiring regeneration.

    2. Convert saved particle results¶

    Simulation particle data are stored in BI4 files such as Part_XXXX.bi4; use PartVTK to convert them, rather than opening BI4 as VTK. Keep associated metadata together with the raw data.

    For existing CasePistonBeach_REG results, use the following post-processing fragment. Open a Windows Command Prompt in examples/main/09_WavesPiston/:

    set "name=CasePistonBeach_REG"
set "dirbin=../../../bin/windows"
set partvtk="%dirbin%/PartVTK_win64.exe"
set "dirout=%name%_out"
set "diroutdata=%dirout%\data"
set "dirout2=%dirout%\particles"

    Adapt the case and executable paths as needed. The commands assume paths without spaces; quote directory arguments when necessary.

    Export fluid particles:

    %partvtk% -dirdata %diroutdata% -savevtk %dirout2%/PartFluid -onlytype:-all,+fluid -vars:+mk

    Export boundary particles separately:

    %partvtk% -dirdata %diroutdata% -savevtk %dirout2%/PartBound -onlytype:-all,+bound -vars:+mk
    Option Purpose
    -dirdata Read particle data. For variable-resolution simulations, current help specifies the main output directory instead; follow that case's workflow.
    -savevtk Write VTK files with the supplied prefix.
    -onlytype:-all,+fluid Select non-excluded fluid particles.
    -onlytype:-all,+bound Select boundary particles, including fixed, moving and floating types.
    -vars:+mk Add the marker field to defaults including particle ID, velocity, density, pressure and type.

    3. Load and animate the VTK series¶

    1. Choose File → Open and browse to the particle-output directory.
    2. Select the grouped PartFluid_*.vtk series, rather than only one frame. Use file-series grouping where offered.
    3. Click Apply, then load/apply the corresponding PartBound_*.vtk series.
    4. Keep both datasets visible and select the fluid item before changing its colour field.
    5. Select an available array such as Rhop (density). In the colour-map editor, choose a preset and show the colour bar.
    6. Rescale to the data range or choose a custom range appropriate to the quantity and comparison. Training-case density limits are not universal fluid settings.
    7. Use Play, pause and time-step controls. Inspect time values/series metadata rather than interpreting a file number as physical time.

    If an expected field is absent, inspect the exported arrays and PartVTK variable selection. Changing the colour map does not calculate missing simulation quantities.

    Basic viewing operations¶

    Toggle dataset visibility to compare fluid and boundaries. Reset the camera when data are out of view, and choose an axis view suited to the geometry; a view along y is useful for an x-z 2-D case. Select the intended dataset/array before editing its colour map or range. The colour bar identifies the displayed range; consistent ranges help comparisons across time or cases.

    Other existing outputs¶

    Result Suitable existing data
    Floating or prescribed-moving body Its boundary/particle series or case-specific body export.
    Moorings Existing mooring VTK series, with particle data; the training example uses MooringsVtk.
    Flexible structure Structure/boundary particle series; the training example also extracts a case-specific tip-particle series.
    Free surface Existing surface VTK, such as IsoSurface output; a gauge CSV is not a complete surface mesh.

    Names and temporal sampling are case-specific. This page does not prescribe extra coupling or surface-generation commands.

    To inspect boundary normal vectors used by mDBC, see the separate How-To on visualising mDBC normals in ParaView.
